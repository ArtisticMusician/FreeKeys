# Free Keys — Photoshop Plugin

**The ultimate keyboard shortcut freedom layer for Photoshop.**

This plugin **always overrides Photoshop’s built-in shortcut restrictions**.

## ✨ Toggleable Feature: Universal Modifier Mode

**OFF (Plain version — default)**:  
**Single key system + modifier keys**  
- Assign bare single keys (just press "S")  
- Plus traditional modifiers (Ctrl+S, Shift+S, Alt+S, Cmd+S, etc.)  
- Normal single-key shortcuts, but way more powerful than native Photoshop.

**ON (2-key sequential system)**:  
- Every first key becomes a group modifier.  
- All commands require **two sequential keypresses**.  
- Held modifiers (Shift/Ctrl/Alt/Cmd) only need to be held **during the first key press**.  
- After releasing the first key you have **3 full seconds** to press the second key.  

**Examples (ON mode):**  
- `S` then `M` → Marquee Selection Tool  
- Hold **Shift** + `S` (release) then `M` (within 3s) → Send to Layers panel  
- Hold **Ctrl** + `S` (release) then `P` → Any other command

## How to Install
1. Download the latest release or build from source.
2. In Photoshop: Extensions → Install UXP Plugin → select the folder or .ccx.
3. Open Free Keys panel from Window → Extensions.
